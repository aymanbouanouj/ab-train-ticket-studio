# Approved branding provenance

AB TRAIN identity assets are copied byte-for-byte from `AB-TRAIN-Logo-Pack/production` by `scripts/integrate-brand.mjs`. The user-supplied canonical PNG remains unchanged in the pack. No vector redraw is used.

- Header: horizontal theme WebP lockups; compact theme PNG lockups on mobile.
- Footer: horizontal theme WebP lockups.
- Ticket: supplied transparent WebP monogram embedded as a data URI in `src/brand.js`, keeping canvas/PNG/PDF/print self-contained.
- Favicons, Apple touch icon and Open Graph: supplied production assets.
- `zellige-divider.svg`: original project-authored geometric line ornament, inspired by the general Moroccan geometric tradition; no copied kit artwork. Decorative only, hidden from print.

The approved mark's source roughness is preserved. This integration does not claim a new vector master or trademark license. Existing third-party social marks retain the provenance in `public/icons/README.md`.
