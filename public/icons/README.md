Used locally for identification beside visible owner-configured profile links; no endorsement implied.

- GitHub and LinkedIn: Simple Icons 11.15.0 SVGs, downloaded from `https://raw.githubusercontent.com/simple-icons/simple-icons/11.15.0/icons/{github,linkedin}.svg`. Simple Icons project CC0 text is retained in `SIMPLE-ICONS-LICENSE.md`. Brand trademarks and applicable brand guidelines remain with their owners; CC0 does not waive trademark rights.
- Beacons is a plain text link to the configured owner profile. The third-party raster logo is not redistributed. No ownership or trademark permission is asserted.
- Envelope, home, ticket and location glyphs: project-authored SVG strokes in `src/icons.js`, consistent with the app's existing icon grid.

Retrieved 14 October 2026. All assets are local; browsing the app makes no requests to icon CDNs.
